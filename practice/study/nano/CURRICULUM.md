# Nano refresher for the CKAD exam

Focus: editing Kubernetes YAML fast in GNU nano.\
Practice file: `practice/study/nano/pod.yaml`.

## Bites

- [x] a. Open, save and exit
- [ ] b. Select a region
- [ ] c. Cut, copy and paste, for a selection and for whole lines
- [ ] d. Move around: line start and end, top and bottom, go to line, search
- [ ] e. Indent and unindent a selected block, undo and redo
- [ ] f. Search and replace
- [ ] g. A `~/.nanorc` for YAML, and `KUBE_EDITOR=nano` for `kubectl edit`
