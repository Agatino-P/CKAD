# Nano refresher for the CKAD exam

Focus: editing Kubernetes YAML fast in GNU nano.\
Practice file: `practice/study/nano/pod.yaml`.

## Bites

- [x] a. Open, save and exit
- [x] b. Select a region
- [x] c. Cut, copy and paste, for a selection and for whole lines
- [x] d. Move around: line start and end, top and bottom, go to line, search
- [x] e. Indent and unindent a selected block, undo and redo
- [x] f. Search and replace
- [x] g. A `~/.nanorc` for YAML, and `KUBE_EDITOR=nano` for `kubectl edit`
