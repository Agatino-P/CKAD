# Nano lessons, condensed

## a. Open, save and exit

`nano <file>` opens the file, or creates the file on first save when the file does not exist.\
`Ctrl+O` writes the file out, asks for the file name, and `Enter` confirms the file name.\
`Ctrl+X` exits, and when the file has unsaved changes nano asks `Y` to save, `N` to discard, or `Ctrl+C` to cancel.\
In the shortcut bar at the bottom, `^` means `Ctrl` and `M-` means `Alt`.

## b. Select a region

`Alt+A` sets the mark at the cursor, and moving the cursor from there highlights everything between the mark and the cursor.\
`Shift` plus an arrow key also starts a selection, and the selection ends at the next move without `Shift`.\
`Alt+A` a second time removes the mark and drops the selection.
